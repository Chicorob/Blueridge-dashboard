# archive/

One-shot scripts that mutated an HTML version of the dashboard via `str.replace`.
They reference an absolute OneDrive path on the original author's machine and are
not runnable elsewhere. Kept for history; not part of the running app.

- `update_dashboard.py` — patched v2_6 → v2_7 (added Corporate Services, Revenue/FTE, etc.)
- `patch_v2_7_to_v2.py` — patched v2_7 → v2 (calendar-aligned periods, prior-year comparisons)
